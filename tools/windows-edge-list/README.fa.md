# ابزار فهرست IP فروز برای ویندوز

این بسته نسخهٔ کامل VPN ویندوز نیست. ابزار مدیریت IP و تست مستقیم لبه است: فهرست دستی را پاک‌سازی و یکتا می‌کند، کاتالوگ کامل عمومی داخل فایل اجرایی دارد و فقط با اقدام کاربر تست TCP80/TCP443/TLS یا دریافت کاتالوگ انجام می‌دهد. DNS، مسیرهای سیستم و فایروال را تغییر نمی‌دهد و درایور یا سرویس نصب نمی‌کند.

## نصب و استفاده

1. در Windows10/11 با .NET Framework4.8 موجود سیستم، Setup را اجرا و «نصب برای من» را انتخاب کنید. Python و دسترسی Administrator لازم نیست. نسخهٔ Portable نیز بدون نصب قابل اجراست. فایل‌ها امضای Authenticode ندارند؛ SHA256 آن‌ها در همان Release منتشر می‌شود. هیچ تنظیم امنیتی ویندوز را خاموش نکنید.
2. از Start، برنامهٔ FOROUZ Edge List را باز کنید. IPها را در کادر ورودی بگذارید یا یک فایل TXT کوچک باز کنید.
3. «بررسی فهرست» را بزنید. فقط IPv4 عمومیِ استاندارد پذیرفته می‌شود؛ فهرست دارای IP خصوصی، URL، کانفیگ یا بیش از۵۱۲ IP یکتا رد می‌شود. کاما، نقطه‌ویرگول و فاصله/خط جدید جداکننده‌اند.
4. خروجی را کپی یا با «ذخیرهٔ TXT» ذخیره کنید. فایل را با روش دلخواه خودتان به گوشی منتقل کنید؛ این ابزار چیزی آپلود نمی‌کند.
5. در فروز: Laboratory → CDN Scanner، یک پروفایل دارای SNI انتخاب کنید و متن IPها را در «فهرست دستی IPv4» بگذارید. VPN خاموش باشد. برای این مسیر کاتالوگ، GitHub یا سرور ایران لازم نیست. تنها همان IPها با TCP80، TCP443 و TLS معتبر بررسی می‌شوند؛ نوع CDN و کارکرد کانفیگ از ورودی دستی تضمین نمی‌شود.

محل نصب برای کاربر فعلی `%LOCALAPPDATA%\ForouzEdgeList` و میان‌بر در Start است. برای حذف، برنامه را ببندید و فقط همان پوشه و میان‌بر FOROUZ Edge List را حذف کنید. فایل‌های TXT که خودتان در جای دیگری ذخیره کرده‌اید حذف نمی‌شوند. نصب در Apps ویندوز ثبت نمی‌شود.

## اسکن رنج‌های آفلاین

تب «اسکن رنج‌های آفلاین» بدون دریافت از اینترنت، کاتالوگ کاملِ همراه نسخه را می‌خواند: Cloudflare، CloudFront، Fastly، GCore و کاندیدهای ASN اکامای. همهٔ دادهٔ JSON عمومی همراه exe و ZIP است؛ نه فقط چند IP نمونه. رنج‌های رسمی و ASN جدا انتخاب می‌شوند. فهرست origin گکور و ASNهای اکامای/AWS معادل لبهٔ CDN تأییدشده نیستند.

provider و نوع رنج را انتخاب کنید. بودجهٔ تست۳۲/۶۴/۱۲۸/۵۱۲ نمونه است؛ برنامه همهٔ IPهای میلیون‌ها رنج را enumerate نمی‌کند. برای TLS نام دامنهٔ SNI سرویس مناسب لازم است. Cloudflare/CloudFront نام تست عمومیِ خود کاتالوگ را دارند؛ برای بقیه دامنهٔ سرویس خودتان را وارد کنید. با کادر SNI خالی، TLS با علامت SKIP تست نمی‌شود. بررسی TLS از trust ویندوز، نام میزبان و پروتکل‌های پیش‌فرض سیستم استفاده می‌کند؛ هیچ پذیرش گواهی نامعتبر وجود ندارد.

VPN را خاموش کنید و «شروع تست» را بزنید؛ مسیر جاری ویندوز سنجیده می‌شود. هر IP نتایج جداگانهٔ TCP80، TCP443 و TLS دارد. اتصال TCP به معنی کانفیگ سالم یا اثبات هویت CDN نیست. «لغو» سوکت‌های درحال‌کار را می‌بندد و نتایج کامل‌شده باقی می‌مانند. دکمهٔ کپی یا TXT فقط IPهای دارای TCP موفق را خروجی می‌دهد؛ آن‌ها را در ورودی دستی اپ اندروید قرار دهید و بعداً خود کانفیگ را امتحان کنید.

منبع پیش‌فرض از دادهٔ جاسازی‌شده یا آخرین cache معتبر است؛ شروع برنامه هیچ دانلود خودکاری ندارد. در صورت نیاز URL مستقیم HTTPS کاتالوگ GitHub یا آینهٔ خودتان را وارد و «دریافت کاتالوگ» را بزنید. username/password، query token، fragment، لینک HTTP و redirect پذیرفته نیست. فایل باید حداکثر۲MB و schema معتبر داشته باشد؛ فایل سالم به‌صورت اتمیک cache می‌شود و دریافت ناموفق، آخرین نسخه را خراب نمی‌کند. تاریخ اصلی داده نمایش داده می‌شود و تغییر نمی‌کند. snapshot آفلاینِ قدیمی با هشدار قابل نمونه‌برداری است؛ دریافت آنلاین فایل بیش از۳۰روز قدیمی را جایگزین نمی‌کند.

محل cache، `%LOCALAPPDATA%\ForouzEdgeToolsData\catalog-cache.json` است. این فایل فقط دادهٔ عمومی کاتالوگ است. ردیف‌های تست در حافظه‌اند و بدون خروجی TXT صریح، گزارش سنجش روی دیسک ذخیره نمی‌شود. این ابزار هیچ رمز یا پروفایلی نمی‌خواهد.

## ساخت از سورس

با Windows PowerShell اجرا کنید:

```powershell
./tools/windows-edge-list/build.ps1
```

ساخت از کامپایلر C# موجود در .NET Framework ویندوز استفاده می‌کند و هیچ وابستگی دانلود نمی‌کند. خروجی در پوشهٔ `outputs/ForouzEdgeList-Windows` کنار مخزن قرار می‌گیرد. تست‌های CLI صحت IPv4، سقف ورودی، CIDRهای عمومی، خواندن کل snapshot جاسازی‌شده، محدودبودن نمونه‌ها، لغو/timeoutِ کار متعلق به تست و یکپارچگی payload نصاب را بررسی می‌کنند؛ این تست‌ها جای بررسی دستی رابط و نصب روی سیستم‌های مختلف را نمی‌گیرند.
